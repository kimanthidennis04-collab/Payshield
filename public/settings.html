Payment Provider Configuration

Payment provider integrations (M-Pesa, Bank, Card processors) require credentials and configuration. These integrations are prepared in the architecture but not yet configured.

M-Pesa: Requires Consumer Key, Consumer Secret, Passkey, and Shortcode

Bank API: Requires API Key and API Secret

Card Processing: Requires Stripe or other processor credentials

AI Provider: Requires API key for business intelligence features
